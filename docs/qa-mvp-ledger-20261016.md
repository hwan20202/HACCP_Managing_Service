# MVP 수불대장 복원 및 별도 재고·수불 현황 QA

## 이번 변경

원료·부자재·완제품 수불대장은 PM MVP의 조회 방식으로 복원한다. 기본 `수불 내역` 탭은 날짜·품목코드·품목명·LOT·구분·입고·출고·LOT 잔량 등을 거래 한 건당 한 행으로 표시한다. `현재고` 탭은 품목당 한 행이며 총재고·사용 가능·사용 불가·최소재고·부족 여부를 보여 준다.

품목명을 누르면 **그 품목의 전체 LOT 현재고와 선택 기간의 전체 입출고 내역**을 한 상세창에서 확인한다. 상세창에서 LOT를 누르면 원래 화면에서 해당 LOT만 조회한다. `품목 전체 수불 보기`를 누르면 전체 LOT를 포함한 품목 조회로 이동한다. 현재 조회 대상은 품목명·전체 LOT 또는 품목명·선택 LOT로 명시한다.

멘토 예시의 가로 비교 화면은 재고 관리 아래 별도 **재고·수불 현황** 메뉴에 둔다. 원료·부자재·반제품/완제품을 선택할 수 있다. 기존 메뉴와 통합 화면의 검색·기간·선택 상태는 각각 보관한다. 기존 수불대장의 `재고·수불 현황`, 현황 화면의 `수불대장으로` 버튼으로 같은 품목 구분의 화면을 오갈 수 있다.

기간 조회의 API·계산 규칙은 그대로다. 빠른 기간 버튼은 선택한 항목을 파란색으로 표시하고, 날짜를 직접 고치면 빠른 선택 표시를 해제한다. 전체/입고/출고 선택과 기간 선택은 독립적이다. 자료가 같은 날짜에 몰려 있으면 서로 다른 기간의 결과 건수가 같을 수 있다.

이 변경은 **화면 구조·진입점·선택 표시**에 관한 것이다. 입고·생산·BOM·LOT 배분·재고 차감·문서 생성·서버 검증 규칙과 기존 QA 데이터는 변경하지 않는다. MVP에 보이던 모든 기능을 새로 구현한다는 뜻은 아니며, 판매 출하·포장배치·2년 조회 등 기존 제외 범위는 그대로다.

## 팀 공유용 QA 변경 안내

입고 → 생산 계획 → 시작 → 원료 투입 → 산출 → 완료, 재고 부족·BOM 외 원료·합계 불일치·중복 저장 검사는 기존 시나리오를 유지한다. 조회 화면 관련 항목만 아래처럼 바꾼다.

| 번호 | 작업 | 기대 결과 |
|---|---|---|
| V01 | 원료·부자재·완제품 수불대장 열기 | 수불 내역 / 현재고 탭. 기본은 거래 한 건당 한 행의 수불 내역 |
| V02 | 수불 내역에서 검색·전체/입고/출고·기간 변경 | 기존과 같은 조회 조건 적용. 선택 기간 버튼 파란색 표시 |
| V03 | 오늘 → 이번 달 → 3개월 등 선택 후 날짜 직접 수정 | 날짜 입력값과 파란색 버튼 일치. 직접 수정하면 빠른 선택 해제 |
| V04 | 수불 내역 또는 현재고에서 품목명 클릭 | 그 품목의 전체 LOT 잔량과 기간 내 전체 입출고가 상세창에 표시 |
| V05 | 상세창에서 LOT 한 행 선택 | 그 LOT만 원래 수불 화면에 표시. 품목명·LOT 조회 대상 표시 |
| V06 | 상세창의 품목 전체 수불 보기 | 해당 품목의 모든 LOT 내역 표시. ‘전체 LOT’ 표시 |
| V07 | 선택 해제 | 현재 검색·기간에 해당하는 전체 품목/LOT 조회 복원 |
| V08 | 별도 재고·수불 현황 메뉴 열기 | 입출고와 LOT별 현재고를 함께 표시. 품목 구분 선택 가능 |
| V09 | 현황 화면의 LOT 행 선택·해제 | 왼쪽 이력만 해당 LOT로 좁혀지고 오른쪽 목록 유지 |
| V10 | 기존 수불대장과 현황 화면을 오가며 다른 검색·기간 사용 | 한 화면의 조건이 다른 화면을 덮지 않음 |
| V11 | 날짜를 10/12 하루·10/16 하루로 직접 조회 | 선택 날짜의 수불만 표시. 현황 화면의 현재고는 날짜와 무관한 현재 잔량 |
| V12 | 각 화면에서 검색 후 엑셀 다운로드 | 기본 수불/현재고는 해당 탭 한 시트, 통합 현황은 입출고·LOT별 현재고 두 시트. 조건 일치 |

문제 제보에는 메뉴 이름, 탭, 검색어, 기간, 품목·LOT, 기대 결과와 실제 결과를 함께 적는다. 화면을 못 찾거나 선택 범위를 이해하기 어려운 것도 사용성 제보로 받는다.

## 검증 및 배포

별도 새 로컬 QA 데이터에서 일반 수불대장과 현황 화면의 분리, 품목 전체/LOT 한 개 선택, 기간 버튼 표시·직접 날짜 수정, 화면 간 필터 독립성, 기존 입고·생산·현황을 포함한 브라우저 30개 항목이 통과했다. JavaScript 예외는 0건이다. 캡처를 검토한 뒤 품목 상세창 폭을 넓혀 LOT와 수불 표가 세로로 잘게 줄바꿈되지 않는지, 다음 입고 창은 기본 크기로 복원되는지 추가 확인했다.

`scripts/project.py check`는 의존성·ruff·포맷·설정·마이그레이션 검사와 Django 784건 실행에서 통과했다(33건 조건부 건너뜀). 화면 로직 검사도 통과했다. 검사 결과는 Git 제외 `tools/qa-ui-results/report.json`과 `tools/qa-mvp-check.log`에 보관했다. 캡처는 `mvp-ledger.png`, `mvp-current-stock.png`, `mvp-item-history.png`다.

이전 패키지 대신 이번 커밋의 새 패키지를 사용한다. 기존과 동일하게 Seeder 없이 QA 데이터를 보존하며, 배포 시 격리된 메모리 DB에서 서버 회귀 검사를 실행한다. 로컬 검증과 원격 배포 여부는 별도로 보고한다.

이번 수정은 아직 원격 서버에 반영하지 않았다. 사용자가 제공한 앞선 성공 배포 로그는 `1d91f9d` 버전이며, 이번 패키지는 그 이후 변경이다. 기존 QA 데이터·첨부는 수정하지 않았다.
