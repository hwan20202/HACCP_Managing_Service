# 최종 전달 자료

2026-10-27 정리 · 대상 소스: `8d931a3` 이후의 이번 문서 정리 변경을 포함한 전달 버전

이 폴더는 바이오닷에서 프로젝트를 이어받아 사용·설치·수정할 때 읽는 자료입니다. 개발팀이 방문해 설치하는 것을 전제로 하지 않습니다. 실제 설치·운영 담당자는 바이오닷에서 정하고, 선택한 환경에서 설치 결과를 확인해야 합니다. 전달 문서가 정리됐다는 사실이 운영 설치 완료를 뜻하지는 않습니다.

| 운영 담당자: 업데이트·백업·복구·장애 대응 | [운영 안내](operations.md) |
| 외주 개발자: 구현 범위·업무 규칙·상세 근거 | [기술 인수인계](developer-guide.md) |

## 함께 전달할 것

- 소스와 정확한 버전: 전달 시 커밋 번호 또는 압축파일의 기준 버전을 별도 기록
- 필요한 업무 자료: 기존 DB, 문서 첨부, 실제 기준정보·배합표·기초재고, 기준서 원본. 새로 시작하는 경우 사용할 자료를 명시
- 설정: 실제 환경 설정, 역할 설정, 접속 주소, 서비스·인증서 설정. 비밀값과 접속정보는 접근을 제한한 경로로 별도 전달
- 운영 정보: 자료 보관·백업 위치, 설치·복구 담당자, 문의 방법

소스 저장소에는 대부분의 실제 업무 자료가 들어 있지 않습니다. [자료 보관 안내](../../data/README.md)를 확인하고, 어떤 자료를 넘겼는지 목록을 남깁니다.

## 확인 상태

현재 문서는 코드와 기존 검증 기록에 맞춰 정리한 전달 기준입니다. 실제 운영 장비에서의 설치·재시작·접속·복구 검증과 최종 사용 승인은 아직 확인하지 않았습니다. 확인 결과는 [남은 작업](remaining-work.md)에 기록합니다.

참고 명세와 개발 중 기록은 [전체 문서 목차](../README.md)에서 구분해 볼 수 있습니다.
