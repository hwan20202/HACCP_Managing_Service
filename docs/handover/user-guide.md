# 주요 업무 사용 안내

화면을 사용할 때의 기본 순서입니다. 실제 사용할 사이트에 전달 버전이 반영됐는지 설치 담당자와 먼저 확인합니다. 테스트 입력은 실제 업무 자료와 구분된 환경에서 진행합니다.

## 1. 담당자 선택과 입고

화면에서 처리할 직원을 선택합니다. 현재는 비밀번호 로그인이 없으며, 이 선택은 누가 처리했는지 기록하는 용도입니다. 문서는 선택한 직원의 역할에 따라 작성·결재 가능 여부가 달라집니다.

입고 화면에서 유형·품목·공급처·담당자·입고일·수량·단위·소비기한·검사 판정을 확인하고 저장합니다. 원료·포장재·구매 반제품을 입고할 수 있습니다. 기본으로 채워진 날짜와 적합 판정도 실제 자료에 맞는지 확인합니다.

기준단위가 kg인 원료를 500g 입고하면 0.5kg으로 반영됩니다. 같은 소비기한으로 여러 번 입고하면 LOT가 나뉘고 번호 뒤에 `-2`, `-3`이 붙을 수 있습니다. 여러 건은 제공된 CSV 양식으로 올리고 미리보기 오류를 확인한 뒤 저장합니다. 한 번에 1~500건을 처리합니다.

입고하면 시험성적서·원산지 증빙·육안검사 문서가 연결됩니다. 적합 입고는 육안검사 문서의 자동 작성완료를 시도합니다. 작성완료가 안 된 문서는 문서함에서 상태와 필요한 입력을 확인합니다. 시험성적서 유무는 해당 LOT의 시험성적서 문서에 연결된 파일로 계산됩니다.

## 2. 재고와 입출고 확인

| 확인하려는 내용 | 보는 위치 |
|---|---|
| 선택 기간의 입출고 | 수불대장 → 수불 내역 |
| 지금 남은 양·사용 가능한 양 | 수불대장 → 현재고 |
| 품목의 LOT와 관련 기록 | 품목명 클릭 → 품목 상세 |
| 지난달 말 등 과거 시점 잔량 | 품목 상세의 LOT별 기간 요약 → 조회 종료일 잔량 |

현재고는 지금의 재고입니다. 과거 기간을 조회해도 과거 재고로 바뀌지 않습니다. 거래 행의 잔량은 해당 거래 직후 그 LOT의 잔량입니다. 같은 LOT 번호라도 품목이 다르면 다른 물량이므로 품목명도 함께 확인합니다.

검색·기간·LOT 조건과 kg/g 표시를 확인하고 조회·다운로드합니다. 인쇄 시에는 상단 ‘인쇄 / PDF’를 눌러 품목을 선택합니다. 전체 선택은 화면 한 페이지가 아닌 조회 결과의 전체 품목을 대상으로 합니다. 품목 상세에서 인쇄하면 그 상세창의 조회 조건을 따릅니다.

## 3. 배합표와 생산

BOM은 제품의 기준 배합표입니다. 생산 화면의 BOM 관리에서 등록·검색·조회합니다. 생산에 연결된 배합을 바꿀 때는 새 버전으로 관리해 기존 생산 기록의 기준을 보존합니다.

1. 생산지시·실적에서 생산 품목과 계획량을 입력하고 원료 소요량·가용량을 확인해 계획을 등록합니다.
2. 제조일을 확인하고 생산을 시작합니다. 이때까지는 원료를 예약하거나 차감하지 않습니다.
3. 남은 원료 일괄 투입에서 실제 사용한 수량과 LOT를 확인합니다. 자동 추천은 실제 사용량을 대신하지 않습니다. 수정 후 확인한 원료를 등록하면 재고가 차감됩니다.
4. 실제 산출량을 등록합니다. 같은 배치에서 0.4kg과 0.6kg을 등록하면 같은 산출 LOT에 1kg이 누적됩니다.
5. 완료하고 연결 수불·문서를 확인합니다. 필수 원료 투입이 빠졌거나 산출이 없으면 완료할 수 없습니다.

EA는 선택적으로 적는 참고 개수입니다. 무게와 자동 환산하지 않으며, 일부만 입력한 개수를 전체 재고 개수로 해석하지 않습니다.

생산 목록의 ‘인쇄 / PDF’에서 여러 배치를 선택해 출력할 수 있습니다. 배치 상세에서는 해당 배치 한 건을 바로 출력합니다.

## 4. 보류와 해제

진행 중 생산에서 문제가 생기면 제조배치 상세의 ‘보류 관리’에서 사유를 남깁니다. 활성 보류가 있으면 경고와 해제 영역을 표시하며 시작·투입·산출·완료를 막습니다. 연결된 산출 LOT에도 보류가 적용됩니다.

개선조치를 확인한 뒤 해제 화면에서 확인 체크와 사유를 입력합니다. 문서 결재와는 별도로 처리하며 문서 승인만으로 자동 해제되지 않습니다. 다른 사유로 LOT에 따로 등록한 보류는 남습니다.

## 5. 문서 작성·결재·출력

문서함에서 연결 문서나 작성할 점검표를 엽니다. 입력·저장 후 필수 내용과 개선조치를 확인하고 작성완료합니다. 결재 요청은 작성완료 상태에서 진행하며, 결재선은 양식별 역할 설정으로 자동 구성됩니다. 결재자는 결재함에서 자신의 칸을 처리합니다. 생산일지는 결재 없이 작성완료로 끝나며(작성 재개로 다시 고침), 작성완료한 일지만 출력합니다.

수정할 수 있는 상태는 작성중·반려·정정 중입니다. 승인된 문서를 고칠 때는 정정 절차를 사용합니다. 새 승인이 끝나기 전에는 이전 승인본이 유효합니다. 수불대장 자체는 시스템 결재 없이 출력 후 별도 결재합니다.

서류 종류마다 출력 단위와 가능한 상태가 다릅니다. 문서 양식별 조작·증빙 첨부·주기 점검표·CCP 대시보드는 [문서·결재 상세 설명](../reference/document-user-guide.md)을 참고합니다.

화면이 없거나 버튼을 사용할 수 없으면 현재 직원·문서 상태·역할 설정·메뉴 노출을 설치 담당자와 확인합니다. 오류를 문의할 때는 화면 이름, 발생 시각, 입력하려던 내용, 오류 문구를 함께 남깁니다.
