# 바이오닷 HACCP 프로그램 전달 안내

2026년 10월 28일 전달용 · 10월 27일 작성 초안

## 1. 이번에 만든 프로그램은 어디까지인가요?

원료를 입고한 뒤, 어떤 원료를 얼마나 사용해 무엇을 만들었는지 기록하고, 남은 재고와 관련 HACCP 서류를 확인하는 프로그램입니다.

**원료 입고 → 생산 기록 → 제조된 제품의 재고 반영 → 입출고 내역·서류 확인**까지가 이번 개발 범위입니다. 제조가 끝난 상태의 제품을 ‘벌크’라고 부르며, 판매용으로 소분·포장하고 고객에게 출하하는 업무는 다음 개발 범위로 남겨두었습니다.

아래는 개발 자료에 기록된 기능입니다. **실제로 사용할 사이트의 준비와 최신 기능 반영은 바이오닷이 지정한 설치 담당자가 확인해야 합니다.** 접속 주소와 문의 담당자는 마지막 확인란에 적도록 했습니다.

## 2. 화면에서 무엇을 할 수 있나요?

| 하려는 일 | 제공하는 기능 |
|---|---|
| 원료가 들어왔을 때 | 품목·수량·소비기한·검사 결과를 등록합니다. 여러 건은 정해진 CSV 파일 양식으로 한꺼번에 올릴 수 있습니다. |
| 재고를 확인할 때 | 품목별·LOT별 남은 양과 입출고 내역을 조회합니다. LOT는 입고 또는 제조한 물량을 구분하는 번호입니다. |
| 생산할 때 | 생산 계획을 만들고, 실제 사용한 원료와 만들어진 양을 입력합니다. 원료 재고와 생산품 재고가 이에 맞춰 반영됩니다. |
| 배합을 관리할 때 | BOM(제품별 기준 배합표)을 등록하고, 변경된 배합은 새 버전으로 관리합니다. 기준 배합과 실제 사용량을 비교할 수 있습니다. |
| 문제가 생긴 생산분을 관리할 때 | 해당 생산 건을 보류하고, 개선조치 확인 후 사유를 남겨 해제합니다. |
| HACCP 기록을 관리할 때 | 입고·생산에 연결된 문서와 주기 점검표를 작성하고, 결재 요청·승인·반려·정정 이력을 확인합니다. |
| 종이나 파일로 받을 때 | 수불대장(입출고 장부)·현재고·생산지시서와 지원되는 HACCP 서류를 인쇄하거나 PDF로 저장합니다. |

생산일지는 제조 배치마다 1건이 생산 시작 때 만들어지고(결재 없음 — 작성중 ↔ 작성완료), 원료·배합·실제 사용량을 수불에서 불러와 공정과 함께 작성·출력합니다(P15). **현업 서식·입력 부담에 맞는지는 실제 사용으로 확인할 항목**입니다.

## 3. 사용하면서 알아두실 결정사항

### 계획을 세우는 것과 재고가 줄어드는 시점은 다릅니다

생산 계획을 등록하거나 생산을 시작하는 것만으로 원료 재고가 줄지는 않습니다. 실제로 사용한 원료를 ‘투입’으로 등록할 때 차감됩니다. 계획한 양을 다른 생산에서 쓰지 못하도록 미리 확보하는 기능은 이번 범위에 없습니다.

### 같은 생산 건에서 나누어 만든 양은 한 LOT에 더합니다

예를 들어 한 생산 건에서 오전에 4kg, 오후에 6kg을 등록하면 같은 제조 LOT에 총 10kg이 쌓입니다. 별도로 진행한 다른 생산 건은 다른 LOT로 관리합니다. 원료는 현재 입고 건별로 LOT를 나누므로, 같은 소비기한의 원료도 번호 뒤에 `-2`, `-3`이 붙을 수 있습니다.

### 현재고와 과거 날짜의 잔량을 구분해서 봅니다

‘현재고’는 지금 남아 있는 양입니다. 지난달을 조회해도 현재고가 지난달 재고로 바뀌지는 않습니다. 지난달 말에 얼마가 남았는지 보려면 선택한 기간의 ‘종료일 잔량’을 확인합니다.

### 생산 보류와 문서 결재는 각각 처리합니다

문서에 문제가 기록되거나 결재가 끝났다고 생산이 자동으로 보류·해제되지는 않습니다. 담당자가 생산 화면에서 직접 보류하고, 개선조치를 확인한 뒤 해제합니다. 보류 중에는 해당 생산 건의 시작·투입·산출·완료를 진행할 수 없습니다. 결재 완료는 보류 해제의 필수 조건으로 두지 않았습니다.

### 입고 검사 판정과 결재 승인은 서로 다른 의미입니다

입고 검사 판정은 원료의 사용 가능 여부에 연결됩니다. 이후 문서 결재를 승인하거나 반려하는 것만으로 그 판정이 바뀌지는 않습니다. 검사 결과를 바꾸려면 검사 기록을 수정하는 절차가 필요합니다.

### 과거 기록은 정정할 수 있고, 승인된 서류는 이력을 남깁니다

지난 날짜의 수불 기록도 정정할 수 있습니다. 이미 승인한 문서는 정정 절차로 수정하며, 새로 승인되기 전까지 이전 승인본이 유효합니다. 수불대장 자체의 결재는 출력물로 별도 진행하는 기준입니다.

### 현재 사용자 선택은 로그인 기능과 다릅니다

현재는 화면에서 처리할 사람을 선택합니다. 선택한 사람의 역할에 따라 문서 작성·결재 버튼을 사용할 수 있지만, 비밀번호로 본인임을 확인하는 로그인은 아직 없습니다. 누가 어떤 문서를 작성·결재할지(HACCP팀장·양식별 담당자·작성 권한자)는 화면 **[문서 권한]**에서 바꾸고, 직원 등록·비활성은 **[시스템] › [설정]** 직원 관리에서 합니다. 바꾼 내용은 누가·언제 바꿨는지 이력이 남습니다. 결재 칸 구성(담당자만·담당자 + HACCP팀장 등)을 바꾸는 것은 개발자에게 요청합니다.

## 4. 이사님과 현장에서 정해주실 내용

| 정할 내용 | 필요한 이유 |
|---|---|
| 실제 업무를 시작할 날짜와 기초재고 기준일 | 바이오닷이 날짜를 정하고 해당 기준일의 실제 재고를 확인해 등록합니다. QA 재고는 승계하지 않습니다. |
| v8 BOM과 관련 기준 자료 | v8 기준정보 초기 DB가 준비됐습니다. 등록 목록과 원본 공란·LOT 기준 차이를 확인합니다. |
| 서류별 작성 담당자와 결재자 | 실제 업무 분담에 맞게 화면 [문서 권한]에서 HACCP팀장·담당자·작성 권한자를 지정해야 합니다. |
| 입력과 출력이 현장 업무에 맞는지 | 자주 쓰는 품목으로 입고부터 출력까지 해 보고, 빠진 항목과 불편한 순서를 확인해야 합니다. |
| 다음 개발에서 우선할 업무 | 판매용 포장·출하 등 추가 업무의 우선순위를 정해야 합니다. |

## 5. 필요할 때 개발자에게 요청할 내용

개발자가 상시 담당하지 않는 상황을 고려해, 다음 내용은 전달받을 때 확인 결과를 남겨두는 것이 좋습니다.

- **사이트에 최신 기능 반영:** 개발한 파일과 실제 접속 사이트의 내용이 같은지 확인해 달라고 요청합니다. 화면 파일을 바꾸는 것 외에 저장 구조 변경이 필요한 기능도 있습니다.
- **초기 DB 설치:** 개발팀이 제공받은 v8으로 기준정보만 담은 초기 DB를 준비했습니다. 바이오닷이 배포 방식을 정하면 설치 담당자에게 전달 DB 배치와 환경 설정을 요청합니다. 기초재고와 실제 업무 기록은 이후 등록하며 QA 거래·잔량은 사용하지 않습니다.
- **백업과 복구:** 무엇을 어디에 백업하며, 문제가 났을 때 누가 어떻게 복구하는지 남겨 달라고 요청합니다.
- **정기 점검표 생성:** 필요한 날짜에 점검표가 만들어지도록 예약 작업이 설정되어 있는지 확인해 달라고 요청합니다.
- **아직 확인할 기능:** 생산일지의 현업 사용 확인(작성 시간·출력 서식)과, 제조배치 취소 시 연결 서류의 처리 방식을 확인합니다. 입고 취소는 사용·결재 상태에 따른 차단과 연결 서류 정리까지 구현되어 있습니다.

추후 수정 요청에는 **화면 이름, 하려던 일, 실제 결과, 원하는 결과**를 함께 적으면 됩니다. 예: “원료 수불대장에서 지난달을 조회했습니다. 현재고는 그대로이고 지난달 말 잔량을 찾기 어려워, 종료일 잔량을 더 눈에 띄게 표시하고 싶습니다.” 오류가 있다면 발생 시각과 오류 문구도 함께 남깁니다.

개발자에게는 [기술 인수인계 자료](developer-guide.md)를 함께 전달하면 됩니다. 세부 결정과 개발 기록은 해당 문서에서 찾아볼 수 있습니다.

## 6. 설치 후 확인할 내용

개발팀이 방문해 설치하는 일정은 전제로 하지 않습니다. [설치·배포 안내](installation.md)를 전달받은 설치 담당자가 준비한 뒤, 실제 업무 기록에 영향을 주지 않는 테스트 자료로 아래 흐름을 확인합니다.

1. 원료 한 품목의 입고 내역·현재고·LOT별 잔량을 확인합니다.
2. 생산 계획 → 실제 원료 투입 → 생산량 등록 → 완료까지 진행하고 재고가 맞는지 확인합니다.
3. 연결된 HACCP 문서를 열고 작성·결재·출력 흐름을 확인합니다.
4. 사용 가능한 화면과 아직 준비 중인 메뉴를 구분해 안내받습니다.

| 전달받을 정보 | 확인 결과 |
|---|---|
| 실제 접속 주소 | 확인 후 기입 |
| 사용할 자료가 테스트용인지 실제 업무용인지 | 확인 후 기입 |
| 사이트에 최신 기능을 반영했는지 / 확인 날짜 | 확인 후 기입 |
| 수정·오류 문의 담당자와 연락 방법 | 확인 후 기입 |
| 소스·업무 자료 보관 위치 | 확인 후 기입 |
| 백업 위치·주기 / 복구 담당자 | 확인 후 기입 |

화면 조작은 [주요 업무 사용 안내](user-guide.md), 문서별 상세 조작은 [문서·결재 사용설명서](../reference/document-user-guide.md)를 참고해 주세요. [남은 작업](remaining-work.md)에는 현업과 설치 담당자의 확인 항목이 있습니다.
