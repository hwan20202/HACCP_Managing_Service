# 남은 확인·추가 협의

2026-10-27 기준. 아래 담당자는 역할 구분이며 실제 인원·계약·작업 일정은 바이오닷에서 정합니다. 개발팀의 현장 방문 설치를 전제로 하지 않습니다.

## 설치·업무 시작 전에 확인

| 구분 | 필요한 확인 | 확인 주체 |
|---|---|---|
| 설치 환경 | Windows PC 또는 별도 서버, 접속 주소·범위·HTTPS·설치 담당자 결정 | 바이오닷·설치 담당자 |
| 전달 자료 | 소스 버전, DB·첨부·실제 자료·설정의 전달 목록과 보관 위치 | 전달자·인수자 |
| 설치 결과 | 전달 버전과 DB 변경 반영, 재부팅 후 자동 실행, 주요 기능과 첨부 열기 | 설치 담당자 |
| 업무 자료 | 실제 품목·배합표·단위·소비기한, 운영 시작일·기초재고 확정 및 이관 확인 | 현업·개발자 |
| 역할·접속 | 실제 작성자·결재자 설정, 로그인 도입 필요성과 접속 제한 결정 | 현업·개발자 |
| 운영 | 백업 주기·별도 보관·복구 연습, 주기 점검표 자동 생성·실패 대응 | 운영 담당자 |
| 현장 적합성 | 자주 쓰는 품목으로 입고→생산→재고→서류→출력 확인 | 현업·설치 담당자 |

## 기능별 확인

- 생산일지: 수불 쪽 데이터 제공은 구현됨. 문서 화면·최종 출력 완성 여부와 배합비의 분모·포함 원료·자릿수는 문서 담당 영역에서 확인
- 제조배치 취소: 취소 후 연결 문서의 처리 정책·동작 확인. 입고 취소는 사용·조정 및 결재 상태에 따른 차단과 연결 문서 논리 삭제가 이미 구현됨
- 현업 적합성: 같은 성적서 재사용, 점검자·개선조치 입력 부담, 하루 문서/주 묶음 출력, 하루 50 LOT 초과 입고 묶음 제약 확인
- 현재 가정: 산출 LOT의 즉시 사용 가능 상태, 배치 번호 형식, 품목별 CCP 공정 적용 등이 실제 운영에 맞는지 확인. [수불 결정](../reference/inventory-decisions.md)과 [문서 결정](../reference/document-decisions.md)의 가정 표 참고

## 다음 범위로 별도 협의

판매용 소분·포장·출하·고객 반품, 재고 예약, 수율·허용 오차, 정정·반품·폐기 입력 화면 확장은 필요성·범위·일정을 별도 합의합니다. CCP 이탈 자동 보류는 이번 완료 조건이 아니며, 현재는 담당자의 수동 보류·해제를 사용합니다.
