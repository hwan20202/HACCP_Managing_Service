# BOM 관리 목록 품목별 접기·펼치기

2026-10-24 · 현재 작업 브랜치 로컬 구현

- BOM을 품목별로 묶고 기본적으로 접어서 표시합니다. 품목코드·품명·최신 버전·버전 수·사용 상태 버전 수를 요약에 표시합니다.
- 품목 그룹은 품목코드 내림차순입니다. 그룹 내부는 진행 중인 배치가 쓰는 BOM → 사용 가능 → 중지 순이며, 각 구분 안에서는 버전 번호 오름차순입니다. 과거 생산 연결 이력(`used`)과 현재 진행 중인 배치의 사용 여부를 구분합니다.
- 품목코드·품명 검색과 10·20·50개 단위 페이지 조회를 제공합니다. 검색 시 첫 페이지로 이동하고, 저장 후 해당 품목이 있는 페이지를 펼칩니다.
- 조회·수정·새 버전·사용 중지·삭제 버튼과 기존 저장 API를 유지합니다. 목록으로 돌아오면 펼친 품목 상태를 유지하며, 저장 후에는 저장한 품목을 펼쳐 표시합니다.
- DB·버전 생성 규칙은 변경하지 않았습니다. 생산 실적 표의 대체 원료 연결에 사용하도록 `bom_check.lines[].bom_line_id`를 응답에 추가했습니다.
- 생산 화면 선택 탭은 파란색으로 표시합니다. 중복 투입 기록 토글은 제거하고 BOM 표에 투입 LOT 링크·정정 반영량을 표시합니다. LOT 상세에는 최초 투입량·정정 반영량과 수불 이력을 제공합니다. 연결 없는 투입도 별도 영역에 남겨 표시합니다.

검증: 실제 Chrome에서 가상 품목 25개·버전 4개씩으로 검색·검색 결과 없음·페이지 이동·진행 중 v2 우선 및 나머지 버전 오름차순을 확인했습니다. 실제 배치의 LOT 상세 조회와 대체 원료·전량 정정·이전 연결 없는 투입 표시, 파란색 탭, 800px 가로 넘침 없음을 확인했습니다. 가상 자료는 브라우저 메모리에만 추가했으며 DB에는 저장하지 않았습니다. 기존 단위·보류·인쇄 프런트엔드 검사 통과. 로컬 캡처: `tools/bulk-production-qa/production-lot-links.png`, `bom-browsing-800.png`.

전체 검사: `scripts/project.py check` 통과(테스트 1,052개, 36개 건너뜀). 로그: `tools/bom-browsing-check.log`.
