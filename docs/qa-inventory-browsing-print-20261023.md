## 화면 변경

- 수불 내역·현재고·품목 상세 수불을 기본 50건씩 표시한다. 25/50/100건, 처음/이전/다음/마지막,
  페이지 번호 직접 이동, 전체 건수와 표시 범위를 제공한다.
- 검색·필터·정렬 변경 시 첫 페이지로 돌아간다. 페이지 이동은 받은 결과를 재사용한다.
- LOT 번호 검색, 조회 조건 초기화, 이전/다음 달 이동을 추가했다.
  기간 역전·누락·1년 초과는 화면에서도 안내한다.
- 생산에서 수불로 이동할 때 이전 LOT 검색을 비우고 해당 배치의 첫 거래가 있는 페이지로 이동한다.
- 수불·현재고 및 품목 상세 선택 기간 수불에 인쇄/PDF 미리보기를 추가했다.
  A4 가로, 반복 표 머리글, 행 단위 페이지 나눔을 사용한다.
  화면의 현재 페이지와 무관하게 필터를 통과한 전체 결과를 출력한다.
  기간·검색·선택 품목/LOT·취소 조건·조회 시점·건수를 명시하고 kg/g 및 EA를 유지한다.
  현재고는 품목 전체 합계이며 소비기한 필터에 해당하는 LOT만의 합계가 아님을 표시한다.
- 새 조회를 시작하는 즉시 이전 결과 캐시를 무효화해 이전 기간 결과를 새 조건으로 인쇄하지 않게 했다.

## 남은 성능 범위

이번 페이지 처리는 DOM의 행 수를 제한한다. API는 여전히 선택 기간 전체 수불과 품목/LOT 결과를 가져온다.
실제 대량 데이터의 DB 조회·전송량을 줄이려면 서버 페이지 조회와 별도의 전체 내보내기 경로가 필요하다.
그때 LOT별 거래 직후 잔량, 이월/종료 잔량, 문서 쪽에서 사용하는 기존 묶음 API 계약을 함께 보존해야 한다.
품목 상세의 LOT 목록과 기간 요약은 현재 전체 표시를 유지한다.

변경은 로컬 작업 브랜치에 있으며 커밋·푸시·배포하지 않았다.

## 후속 수정: 품목 상세 X 닫기

상세창 필터·LOT·페이지 이동이 여러 history 항목을 만드는 상태에서 X가 `history.back()`을 호출해,
닫는 대신 직전 상세 상태를 복원하는 문제를 수정했다. X와 배경 클릭은 창을 즉시 숨기고 현재 이력을
닫힌 상태로 교체한다. 부모 조회 조건은 유지하며, 브라우저 뒤로/앞으로의 이력 복원은 그대로 제공한다.
닫는 순간 진행 중인 이력 복원과 품목 상세 요청을 무효화해 늦은 응답의 재렌더링을 차단한다.

확장한 `test_navigation_frontend.cjs` 및 기존 JS 검사 모두 통과.
격리 DB의 실제 Chrome에서 상세 여러 번 조작 후 X 한 번, 닫은 뒤 새로고침, 뒤로 가기로 상세 복원 후
X, 응답 지연 중 X를 눌렀을 때 닫힌 상태 유지를 확인했다.
