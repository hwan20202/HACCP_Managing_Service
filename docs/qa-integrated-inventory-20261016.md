- 원료·부자재·완제품 메뉴 모두 같은 모듈로 현재 재고와 개별 수불을 한 화면에 표시한다.

- 스크린샷 첨부는 이번 요청에서 확인되지 않아 기존 디자인과 명시된 요구사항 기준으로 구성했다.

## 실행 방법·주의사항

이 보고서 작성 당시에는 개발 설정에서만 실행 가능했다. `seed_qa_inventory --stage prepare`는 재고 준비, `--stage run`은 생산 시나리오와 검증을 수행한다. 각 실행은 자동 백업하며 하나의 DB 트랜잭션에서 적재·검증한다. 동일 날짜/시나리오의 재실행 중복 방지는 자동 테스트로 확인했다. 이후 전용 QA 설정·명시적 허용·DB 완료 기록에 따른 재실행 방지를 보완했으며 현재 동작은 [호스팅 QA 준비 검증](qa-hosted-preparation-20261016.md)과 [배포 준비](cafe24-qa-deployment.md)를 따른다.

브라우저 QA나 수동 작업으로 추가 거래를 만든 후에는 시나리오 초기 예상값과 달라질 수 있다. 이미 실행한 날짜의 prepare를 초기화 명령으로 쓰지 않는다. 이번 최종 기대값은 브라우저 추가 거래까지 반영했다. 기존 거래를 지우거나 재고를 직접 덮어써 초기화하지 않는다.

기록된 데이터는 QA 가정값을 포함하므로 운영 기초재고로 사용하지 않는다. CCP 이탈 자동 HOLD·취소 문서 처리를 새 정책으로 구현하지 않았다. 대시보드·기존 생산 일지 등 다른 시제품 화면은 이번 범위 밖이다.
