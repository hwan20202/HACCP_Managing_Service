# 개발 당시 기록

이 폴더는 개발 과정의 계획·변경·검증 근거를 보관합니다. 현재 기능이나 실제 서버 상태를 보증하는 자료가 아닙니다. 현재 사용·설치 기준은 [전달 자료](../handover/README.md), 업무 규칙은 [참고 명세](../reference/README.md)를 먼저 확인합니다.

| 폴더 | 내용 |
|---|---|
| planning/ | 초기 로드맵·화면 비교·ERD 검토·문서 개발 단계 설명 |
| changes/ | 날짜별 피드백·10/19 인수인계·과거 사용자 안내 |
| qa/ | 날짜별 기능 검증·테스트 시나리오·화면 개선 기록 |
| deployment/ | 기존 카페24 QA 준비·자동 배포, 정리 전 설치 문서 원본 |

주요 근거는 [10/24 보류](qa/qa-production-holds-ui-20261024.md), [선택 인쇄](qa/qa-bulk-print-20261024.md), [생산일지 데이터](qa/qa-production-journal-sources-20261023.md), [입고·조회 검토](qa/qa-inventory-browsing-print-20261023.md)입니다.

날짜는 기능 변경·기록 당시 기준이며 나중에 Git에 반영된 날짜와 다를 수 있습니다. 이전 ‘미정’ 항목은 이후 구현됐을 수 있고, 이전 배포 명령은 특정 서버·버전 전제일 수 있습니다. 특히 개발 DB 재생성·샘플 적재 지시를 실제 업무 DB에 적용하지 않습니다.
