# 생산 실적 LOT 표시 정리

- BOM 표의 수량 이름을 `기준량`, `총 투입량`, `LOT별 사용량`으로 구분합니다. 총 투입량과 LOT별 사용량은 모두 정정을 반영합니다.
- 한 원료를 여러 LOT로 투입하면 BOM 원료·기준량·총 투입량은 병합 셀에 한 번 표시하고, LOT별로 행을 나눕니다. LOT 링크·사용 원료·LOT별 사용량을 각각 별도 열에 정렬하며 대체 원료를 구분합니다.
- LOT 상세에서 최초 투입량과 정정 반영량을 확인하는 동작은 유지합니다. 연결 없는 투입도 별도 표에 남습니다.
- 선택 탭의 배경·글자·포커스 스타일을 수불대장과 동일하게 맞춥니다.
- 완료·취소 배치의 일반 안내 카드를 제거합니다. 진행 안내와 보류 안내는 유지합니다.
- 배치 머리의 내부 BOM id 대신 `BOM v1` 형태의 버전을 표시합니다.

검증: 단위·보류·인쇄 프런트엔드 검사 통과. 실제 로컬 Chrome에서 3개 LOT의 0.5/0.2/0.3kg 분할 투입(대체 원료 포함), 병합 셀, LOT 링크, 정정 표시, 완료 안내 제거, BOM 버전, 공통 탭 색상, 800px 화면을 확인했습니다. 가상 분할 자료는 브라우저 메모리에서만 사용했습니다.
