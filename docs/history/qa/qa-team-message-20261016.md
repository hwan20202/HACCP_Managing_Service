# 팀 공유용 안내문 (재배포·기본 접속 확인 후 공유)

재고·생산 QA를 요청드립니다.
접속: https://175-118-124-141.sslip.io/ (QA 비밀번호는 별도 전달)

이번에는 새 QA 기본 자료와 완료 생산배치 3개로 시작합니다. 이전 테스트 DB·첨부는 보존합니다.

- 테스트 범위: BOM 밖 원료 차단, 허용 대체 원료, 여러 LOT 합산·분할 투입, 재고 부족 시 생산 시작 차단, 필수 원료 누락 시 완료 차단, 입고→생산→재고·수불·문서 연결.
- 화면 확인: 품목명·코드 검색, 아이패드 조작, 소비기한 있음/없음 전환, 총재고/가용재고/사용 불가 구분, 취소 배치 필터.
- 미구현/미확정: 재고 예약, 계획 배치 삭제, 포장·출고, 역할별 권한, CCP 이탈 자동 HOLD, 실제 수율·허용 오차 기준. 생산 시작은 재고 예약이 아닙니다.
- 시나리오: `docs/history/qa/qa-manual-scenarios-20261016.md`의 Q01~Q22. 신규 배치 메모에 `수동QA-날짜-이름`을 남겨 주세요.

오류 제보: **테스트 번호 / 한국시간 / 기기·브라우저 / 품목·LOT·배치·문서 번호 / 재현 순서·수량 / 기대 결과와 실제 결과 / 오류 문구·캡처**. 재고 문제는 전후 잔량도 부탁드립니다. 비밀번호·토큰은 제보에 넣지 말아 주세요.
