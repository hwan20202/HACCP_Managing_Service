# 기간별 수불 현황: 단일 표와 기간말 잔량

> 후속 통합으로 대체됨: [수불대장·현재고·품목 상세 통합](qa-unified-inventory-20261019.md). 별도 현황 메뉴는 제거하고, 종료일 잔량은 공통 상세창의 LOT별 기간 요약에 한 번 표시한다. 아래는 이전 설계·검증 기록이다.

2026-10-19 사용자 선택 반영. 기존 재고·수불 현황의 좌우 표를 하나로 합친다. 오른쪽의 현재고는 제거하고, 수불 표에 **조회 종료일 기준 기간말 LOT 잔량**을 추가한다. 10/16 현황 화면과 10/18 현재고 개선 기록 이후의 변경이다.

## 화면별 역할

| 화면 | 조회 목적 | 재고 기준 |
|---|---|---|
| 각 수불대장 → 수불 내역 | 거래를 한 건씩 검색·확인 | 각 거래 직후 LOT 잔량 |
| 각 수불대장 → 현재고 | 품목 합계와 선택 품목 LOT 잔량을 함께 확인 | 지금 재고 |
| 재고·수불 현황 | 품목별로 묶은 기간 내 입출고·이월과 기간말 잔량 대조 | 조회 종료일의 LOT 잔량 |

현황의 열은 수불일자 / LOT / 입고 / 출고 / 수불 후 잔량 / 기간말 LOT 잔량이다. 마지막 열에 기준 종료일을 표시하고, 품목 구분 행에는 중복 없는 기간말 품목 합계를 표시한다. 같은 LOT의 기간말 값은 각 수불 행에 반복되므로 이 열을 행끼리 합산하지 않는다.

기간말 잔량은 기존 수불 API의 `lot.closing`을 사용한다. 시작일 전 이월과 종료일까지의 입출고를 모두 반영하며, 화면의 입고/출고 필터에 따라 다시 계산하지 않는다. 종료일이 같으면 시작일을 바꾸더라도 같은 LOT의 기간말 잔량은 같다. 종료일이 바뀌면 그 사이 수불에 따라 잔량이 달라진다.

현재고 API를 별도로 호출하지 않는다. 과거에 소진된 LOT의 수불·기간말 0도 표에 남는다. 현황 화면에서 의미가 없어진 ‘소진 LOT도 현재고에 표시’ 옵션은 제거했다. 현재고 탭의 소진 LOT 포함 옵션은 유지한다.

**전체 버튼**은 입출고 구분, 선택 품목·LOT 및 상세 LOT 번호 조건을 해제한다. 검색어와 기간은 유지한다. 기존 선택 해제 버튼을 찾지 않고도 현재 조회 범위로 복귀할 수 있다.

현황 엑셀은 입출고 한 시트이며 종료일이 명시된 기간말 LOT 잔량 숫자 열을 포함한다. 현재고 탭 엑셀은 기존대로 품목 합계 / 선택 품목 LOT 현재고 두 시트다. 작업 시작 전에 있던 메뉴·조회 기간 기반 다운로드 파일명 변경도 보존했다.
