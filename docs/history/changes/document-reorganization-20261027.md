# 문서 정리 기록 — 2026-10-27

## 분류

- handover: 이사님 개요·사용법·남은 작업·설치·운영·개발 인수인계
- reference: 구조·수불/문서 결정·앱 연동 계약·문서 상세 사용법
- history/planning: 초기 로드맵·ERD·화면 검토·문서 개발 과정
- history/changes: 피드백 반영·이전 인수인계·이전 사용자 안내
- history/qa: 날짜별 QA·검증 기록
- history/deployment: 기존 카페24 QA 배포 기록과 정리 전 설치 안내 사본

40개 기존·초안 문서를 분류하고 목차·운영·사용·남은 작업 문서를 보완했습니다. 파일 경로가 바뀌어 문서 링크와 소스의 문서 경로 안내도 갱신했습니다. 기존 migration·SQL 파일은 배포 비교에 영향을 주지 않도록 변경하지 않았습니다. 그 안의 예전 docs 경로는 같은 파일명의 history/planning 또는 reference에서 찾습니다.

## 내용 정정

- 입고 취소의 연결 문서 논리 삭제는 이미 구현되어 있어 ‘미정’ 설명 수정. 수불 진입점의 결재 상태 차단과 문서 정리 서비스 자체의 범위 구분
- 문서 연동의 옛 설계 함수 이름·인자를 실제 서비스에 맞게 정리. 미구현 함수를 호출 예시에서 제외
- 수불 기간 잠금은 이번 범위에서 제외. CCP 자동 보류는 10/24 수동 보류·해제 운영 결정으로 정리
- 보류 중 완료 가능이라는 옛 설명을 실제 서버의 완료 차단에 맞게 수정
- 업무 저장·파일 관리·역할 권한이 없다는 옛 설명 수정. 개인별 로그인 미구현과 구분
- 설치 시 기본 양식 등록·실제 기준정보·역할·문서 메뉴 설정 추가. 대상 환경 설치 검증은 미확인으로 표시
- 방문 설치·시연을 전제로 하지 않고 인수자가 지정한 설치·운영 담당자가 확인하도록 전달 문구 수정

실제 서버·DB·설정·업무 자료는 이번 정리에서 변경하지 않았습니다. 현재 사용 기준은 [문서 목차](../../README.md)에서 확인합니다.
