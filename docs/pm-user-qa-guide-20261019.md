# 바이오닷 주요 기능 사용 안내

최종대 이사님 검토용  |  2026년 10월 19일

입고·생산·재고 화면에서 사용할 수 있는 주요 기능과 간단한 이용 예시를 정리했습니다. 익숙한 기능은 건너뛰고 필요한 부분만 참고하시면 됩니다.

### 재고와 수불은 어디에서 보나요

| 확인할 내용 | 사용할 화면 |
|---|---|
| 기간 중 입고와 출고 내역 | 수불대장 → 수불 내역 |
| 지금 남아 있는 재고와 사용 가능한 양 | 수불대장 → 현재고 |
| 품목의 전체 LOT와 관련 거래 | 어느 탭에서든 품목명 클릭 → 품목 상세 |

원료·부자재·완제품 수불대장은 모두 같은 방식으로 사용합니다. 품목 상세 한 곳에서 현재 재고 요약 → 전체 LOT별 잔량 → 선택 기간의 수불 이력을 볼 수 있습니다.

### 예시  덱스트린의 재고와 과거 거래 확인

1. 원료 수불대장에서 덱스트린 또는 품목코드 1000040으로 검색하고, 확인할 기간을 선택합니다. 전체·입고·출고로 거래를 나눠 볼 수 있습니다.

2. 품목명을 누르면 현재 총재고·사용 가능·사용 불가와 LOT 목록이 함께 열립니다. LOT를 누르면 아래 수불 이력만 해당 LOT로 좁혀집니다.

3. 다시 전체 LOT를 보려면 상세창의 전체를 누릅니다. 현재고 탭에서 상세창을 열어도 아래 수불 조회 기간을 변경할 수 있습니다.

현재 재고는 조회 시점 기준이고, 수불 내역은 선택 기간 기준입니다. 과거 기간을 조회해도 현재 재고가 과거 잔량으로 바뀌지는 않습니다.

과거 잔량이 필요하면 LOT별 기간 요약의 조회 종료일 잔량을 확인합니다. 거래 행에 표시된 잔량은 각 거래 직후 그 LOT에 남은 양입니다.

### 조회하면서 알아두면 편한 기능

- 오늘·이번 달·3개월·6개월·1년으로 기간을 빠르게 바꾸거나 날짜를 직접 입력할 수 있습니다. 품목명·코드·LOT로 검색할 수 있습니다.
- 수불대장의 전체는 선택 품목·LOT와 입출고 구분을 해제합니다. 검색어와 기간은 유지하므로, 모든 품목을 보려면 검색어도 지워 주세요.
- 엑셀 다운로드는 보고 있는 탭의 조회 범위로 저장됩니다. 품목 상세에서는 현재 재고·전체 LOT·기간 요약·수불을 4개 시트로 받습니다.

## 입고와 생산 기록하기

### 입고  원료 500g 등록 예시

입고에서 유형과 품목을 선택하고, 공급처·담당자·입고일·수량·단위·소비기한 유무·검사 판정을 입력해 저장합니다. 원료·포장재·구매 반제품을 선택할 수 있습니다.

기준 단위가 kg인 원료를 500g 입고하면 0.5kg으로 반영됩니다. 저장 후 수불대장에서 입고 내역과 재고를 볼 수 있습니다.

현재는 입고 건마다 내부 LOT를 나눕니다. 같은 소비기한이라도 -2, -3 등으로 구분될 수 있으며, 품목별 현재고에서는 각 LOT 잔량을 합산해 보여 줍니다.

### 생산  녹용분말 1kg 제조 예시

1. 생산지시·실적 → 새 생산 계획에서 녹용분말과 계획량 1kg을 입력합니다. BOM 소요량·가용량을 보고 계획 등록을 누릅니다. 계획만 등록하면 재고는 줄지 않습니다.

2. 배치를 선택하고 제조일을 확인한 뒤 생산 시작을 누릅니다. 재고가 부족하면 부족량을 안내하고 시작을 막습니다.

3. 진행 중인 배치에서 남은 원료 일괄 투입을 누릅니다. 제안된 수량·LOT를 확인하고, 실제 사용한 내용에 맞게 수정한 뒤 확인한 원료 일괄 등록을 누릅니다. 이때 원료 재고가 차감됩니다.

4. 제조 후 산출량을 등록하고 완료합니다. 같은 배치에서 0.4kg과 0.6kg을 나눠 산출하면 같은 산출 LOT에 1kg이 누적됩니다.

### 원료가 많을 때는 일괄 투입

BOM 원료를 하나씩 열지 않고 기준량·기등록량·이번 실제 투입량·LOT 배분을 한 표에서 확인합니다. 예를 들어 원료 18개 중 3개를 기준량만큼 등록했다면 나머지 15개만 불러옵니다.

- 다르게 사용한 원료만 수량을 수정하고 LOT를 다시 자동 배분하거나 직접 나눠 입력합니다. 이번에 투입하지 않는 원료는 선택을 해제합니다.
- 자동 제안은 실제 사용량을 대신하지 않습니다. 합계가 맞지 않거나 재고가 부족하면 등록을 막고, 하나라도 실패하면 이번 선택 전체를 저장하지 않습니다.

### 연결 기록과 재고를 함께 확인

수불의 관련 기록 또는 생산 화면의 연결 문서·재고·수불 이력에서 입고 기록, 제조배치, 연결 문서를 열 수 있습니다. 총재고 중 검사대기·부적합·보류·기한 경과분은 사용 가능 재고와 구분됩니다.

현재 제조 범위는 벌크 반제품까지이며, 문서 작성·결재는 별도 흐름입니다. 사용 중 불편한 부분이 있으면 품목·LOT 또는 배치번호와 화면을 함께 알려 주세요.
