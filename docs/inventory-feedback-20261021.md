# 입고·생산·수불 피드백 반영

기준: main `cc23a25` · 작업 브랜치 `feature/inventory-feedback-bom`

## 적용 범위

- 생산 화면의 **BOM 관리**: 신규 등록, 미사용 배합 수정·삭제, 복사해 새 버전 등록.
  생산 계획에 연결된 배합 수정은 새 버전 생성, 삭제는 사용 중지다.
  생산 품목·기준량·적용일·구성 원료·대체 원료·메모를 입력한다. kg/g 입력을 기준단위로 환산한다.
- 수불대장의 **입고 일괄 업로드**: CSV UTF-8 양식, 1~500건, 미리보기 검증 후 저장.
  오류는 행 번호로 안내하고 전체 저장을 롤백한다. 동일 요청 재시도는 중복 입고를 만들지 않는다.
- **품목 삭제**: 전체 선택 또는 개별 선택 후 삭제할 LOT·입고·수불·문서 수를 미리 확인한다.
  생산·다른 BOM·보류·결재·첨부·공유 문서 등에서 사용된 품목은 보호한다.
  미사용 품목과 입고 이력만 영구 삭제하며 작업 감사 기록은 남긴다.
- **생산지시 출력**: 선택 배치의 품목·계획·BOM 소요량·투입 LOT·산출을 인쇄하거나 브라우저에서 PDF로 저장한다.
- **단위**: 수불·현재고·상세·내려받기의 kg/g 표시 전환, 생산 계획·산출의 kg/g 입력,
  BOM 소요량 kg/g 표시. 십진 문자열 환산으로 부동소수점 오차를 피하고 기준단위 6자리 초과는 거부한다.
- **EA**: 입고·산출의 참고 개수 선택 입력, 수불 및 내려받기 표시. 미입력은 미확인으로 취급한다.
  무게와 자동 환산하거나 일부 입력의 합계를 전체 개수 재고로 취급하지 않는다.
- **LOT 필터**: 품목 상세의 현재 LOT 목록에 잔량과 소비기한 필터 추가. 기간 수불·요약의 위치와 계산은 유지한다.
- **생산 재고·수불**: 이 배치의 투입/산출량과 LOT 현재고를 먼저 표시하고 거래 표는 접어서 제공한다.
- **수불 연결**: 생산에서 원료/완제품 수불대장으로 이동하면 제조일~오늘을 조회하고 배치 관련 거래를 강조·스크롤한다.
- **입고 기본값**: 소비기한 있음, 오늘의 다음 해 같은 날에서 하루 뺀 날짜, 검사 적합.
  직접 수정하거나 소비기한 없음을 선택할 수 있다. 윤년 2월 29일은 다음 해 2월 말일을 기준으로 하루를 뺀다.

품목의 식품유형 열 추가, 용어 변경, 생산 정정·보류 화면은 이번 범위에 포함하지 않았다.
자가품질검사의 유형별 시기 알림·외부 성적서 첨부는 문서 쪽 접수 항목이다.
생산 관련 문서 담당자가 요청하는 메소드·뷰·서류 구성은 별도 협업 요청에 맞춰 지원한다.

## 배포 조건

GitHub의 `QA_AUTO_DEPLOY=true`와 배포 키/접속 설정 존재를 확인했다.
[main cc23a25 검사·코드 배포 실행](https://github.com/hwan20202/HACCP_Managing_Service/actions/runs/39533629654)은 성공했다.

이번 변경에는 `inventory.0008_movement_ea_and_unused_purge` 마이그레이션이 있다.
기존 자동 배포는 `--code-only`로 migration·SQL 변경을 중단시키므로 **일반 main 병합만으로 배포 완료되지 않는다**.
자동 배포 보호는 완화하지 않는다. 배포 전 기존 DB·첨부 백업과 대상 커밋을 확정하고,
서버의 현재 migration 상태 및 백업 복구 절차를 확인한 뒤 별도의 DB 변경 배포가 필요하다.

마이그레이션은 수불에 nullable EA를 추가하고 미사용 품목 삭제의 제한된 DB 예외 범위를 추가한다.
일반 수불 수정·삭제 API/ORM 차단은 유지한다. 수불 삭제 예외는 서비스 트랜잭션 내의 삭제 대상 LOT에만
열리고 생산·보류·기타 업무 이동이 있는 LOT은 DB에서도 차단한다.
